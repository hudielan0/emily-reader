# Emily阅读 · 产品设计

> 状态：初稿（2026-11-04）。先定方向，功能细节到动手做每一版时再补。

## 一句话定位

一个在自己电脑浏览器里使用的 EPUB 阅读器，先做到「能舒服地读完一本书」，再加上现成阅读器没有的划词功能。

## 给谁用

- **主要用户：Emily 自己。** 主要读中文书，也读英文书，文件基本都是 EPUB。
- 公开记录开发过程（build in public），也当作求职作品集的一部分。

## 为什么要自己做

Apple Books、微信读书已经免费，基础阅读做得也好。只做基础功能，没有理由换着用。
所以拆成两步：

- **第一版**验证「能用」：打开、阅读、关掉后接着读，全程不卡壳。
- **第二版**验证「值得用」：划词功能就是选它不选别的阅读器的理由。

## 版本规划

| 版本 | 内容 | 要回答的问题 |
|---|---|---|
| 第一版 | EPUB 基础阅读 | 能不能用它顺利读完一本书？ |
| 第二版 | 划词（翻译 / 解释 / 存知识卡片，具体到时候再定） | 会不会因为这个功能放弃别的阅读器？ |
| 以后再说 | 见下文「暂不做」 | — |

## 第一版功能

| # | 功能 | 说明 | 验收标准 |
|---|---|---|---|
| 1 | 打开 EPUB | 从电脑上选一个 `.epub` 文件打开 | 中文书和英文书各打开一本，文字、图片显示正常，没有乱码 |
| 2 | 翻页 | 按键盘左右键或点按钮翻页 | 从第一页连续翻到最后一页，中间不出错 |
| 3 | 章节目录 | 显示目录，点一下就跳到对应章节 | 随便点 3 个章节，都跳对位置 |
| 4 | 记住读到哪里 | 每本书单独记住阅读位置 | 读到第 3 章后关掉网页，重新打开还停在原来那一页 |
| 5 | 字号 / 深色模式 | 调字号；在浅色和深色之间切换 | 改完以后关掉再打开，设置还在 |

**中文书要特别注意排版：** 字体、行距和段落间距，要按中文阅读习惯调，不能直接沿用英文网页的默认样式。

**第一版完成的标准：** 用它完整读完一本中文书，中途没有因为功能缺失或出错而换回别的阅读器。

## 暂不做

| 功能 | 为什么推迟 |
|---|---|
| PDF | 版面固定，不能按屏幕重新排版，做法和 EPUB 完全不同，工作量大很多 |
| 书架 / 书库管理 | 一次只读一本书的话，用不着 |
| 多设备同步、注册登录 | 要用服务器，第一版只在一台电脑上用 |
| 手机 App | 先在电脑上验证有用，再考虑手机 |
| 书店 / 下载书 | 不是这个产品要解决的问题 |

## 技术形式（只定方向）

- 本地网页，在自己电脑的浏览器里打开，不用上传，也不用联网。
- EPUB 的解析和显示用现成的开源工具（候选：epub.js），不自己从头写。
- 阅读位置和设置存在浏览器里。
